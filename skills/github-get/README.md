# GitHub-Get Skill

## 📖 简介

**GitHub-Get** 是一个自动化 GitHub 项目分析 Skill，能够：

- 🔍 自动获取和分析 GitHub 项目
- 📝 生成完整的项目分析报告
- 🧠 将分析结果存入记忆系统
- 📊 维护项目索引和统计

---

| 触发类型 | 触发条件 | 示例 |

## 🔄 重复项目处理

**重要：当用户发送已分析过的项目链接时，不会自动重新分析！**

### 处理流程
```
用户发送 GitHub 链接
        ↓
检测是否已分析过
        ↓
┌───────┴───────┐
│               │
已分析过        未分析过
│               │
↓               ↓
跳过分析        正常分析
↓               ↓
提示用户        生成文件
↓               ↓
输出已有结果    存入记忆
↓               ↓
询问是否更新    输出报告
```

### 检测方法
```bash
# 1. 查询记忆系统
recall_memory(query="{项目名称} {owner}/{repo}")

# 2. 检查文件是否存在
ls "D:/1CHATGPT/btc/Google-BoKe/999-小说/项目分析/" | grep -i "{repo}"

# 3. 检查总索引
grep -i "{repo}" ~/.pi/agent/memory/l1/*-seven-projects-index.md
```

### 用户选择
- **更新** 或 **重新解析**：执行完整更新流程，覆盖原有结果
- **查看**：输出完整的详细分析内容
- **跳过** 或直接忽略：不做任何操作
