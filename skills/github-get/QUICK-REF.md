## ⚡ 触发条件速查

### ✅ 会触发

```
直接链接：
  https://github.com/owner/repo

分析请求：
  帮我分析这个项目
  解析一下这个仓库
  看看这个项目
  了解这个仓库

同样要求：
  按照同样的要求处理
  同样的要求
  跟之前一样

批量处理：
  这几个你逐个处理
  逐个按照要求处理
  [多个 GitHub 链接]
```

### ❌ 不会触发

```
只是提到 GitHub：
  我喜欢用 GitHub
  GitHub 是一个好平台

非项目链接：
  [粘贴代码]
  [其他网站链接]
```

## 🔄 重复项目处理

**已分析过的项目不会重新分析！**

```
用户发送链接 → 检测是否已分析过
                    ↓
        ┌───────────┴───────────┐
        ↓                       ↓
    已分析过                  未分析过
        ↓                       ↓
    跳过分析                  正常分析
        ↓                       ↓
    提示用户                  生成文件
        ↓                       ↓
    输出已有结果              存入记忆
        ↓                       ↓
    询问是否更新              输出报告
```

**用户回复 "更新" 或 "重新解析" 时才执行更新！**
