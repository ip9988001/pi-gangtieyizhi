# INDEX记忆反馈规则

## 反馈定义

INDEX记忆反馈是将使用信号最小同步到INDEX导航投影的机制。

## INDEX定位

### INDEX是导航投影
- **说明**: INDEX是记忆系统的导航投影，不是真相源
- **作用**: 提供快速导航，指向重要条目
- **限制**: INDEX不存储条目正文，只存储导航信息

### INDEX不是真相源
- **说明**: 条目正文是真相源，INDEX只是投影
- **方式**: INDEX从条目层同步信息，不独立存储
- **限制**: INDEX不应替代条目层

## 反馈规则

### 规则1: 只影响HOT/WARM的信号进入INDEX
- **说明**: 只有热度为HOT或WARM的条目才考虑进入INDEX
- **方式**: 通过热度过滤，不将所有条目放入INDEX
- **限制**: COLD条目不进入INDEX

### 规则2: 不是每次命中都大改INDEX
- **说明**: INDEX更新应低频，不是每次命中都更新
- **方式**: 定期批量更新，不实时更新
- **限制**: 避免INDEX频繁变动

### 规则3: 低噪音导航反馈
- **说明**: INDEX反馈应低噪音，不影响导航体验
- **方式**: 只添加真正重要的条目，不添加噪音
- **限制**: 避免INDEX膨胀

## 反馈流程

```
recall命中
    ↓
更新条目last_accessed和access_count
    ↓
检查热度 → HOT/WARM?
    ↓
是 → 考虑添加到INDEX
    ↓
检查INDEX是否已包含 → 未包含?
    ↓
是 → 添加到INDEX
    ↓
否 → 跳过
```

## 反馈字段

### INDEX条目最小字段
- **title**: 条目标题
- **path**: 条目路径
- **summary**: 条目摘要
- **热度**: HOT/WARM/COLD
- **最后访问**: last_accessed

### INDEX条目可选字段
- **keywords**: 关键词
- **state**: 状态
- **freshness**: 新鲜度

## 反馈维护

### INDEX更新
- **条件**: 条目热度变为HOT/WARM，且未在INDEX中
- **操作**: 添加条目到INDEX
- **频率**: 定期批量更新

### INDEX清理
- **条件**: 条目热度降为COLD，或在INDEX中但已过时
- **操作**: 从INDEX中移除条目
- **频率**: 定期检查

## 注意事项

1. **INDEX是导航投影**: 不是真相源，只提供导航
2. **低频更新**: INDEX更新应低频，不是每次命中都更新
3. **低噪音**: INDEX反馈应低噪音，不影响导航体验
