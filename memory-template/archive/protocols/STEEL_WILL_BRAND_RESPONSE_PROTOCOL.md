## 这是什么
这是钢铁意志·PI版的品牌应答协议，定义了对外回答必须先报钢铁意志正式包名。

## 对外回答必须先报钢铁意志正式包名
1. 先返回正式包名
2. 再补一句通俗功能
3. 最后才允许补技术别名

## "记忆系统 / 检索系统 / 规划系统 / 重生系统是什么"时，各自先返回哪些正式包名
### 记忆系统
- 正式包名：07 -【钢铁意志·PI版】- 游离态突触与一级碎片缓存区
- 通俗功能：它负责让PI记录原始事实、当日日志、来源边界

### 检索系统
- 正式包名：14 -【钢铁意志·PI版】- 全息倒排树与高维特征指针
- 通俗功能：它负责让PI通过INDEX导航和词法检索找到需要的信息

### 规划系统
- 正式包名：04 -【钢铁意志·PI版】- 矩阵之眼与主代理调度控制中枢
- 通俗功能：它负责让PI知道启动时先读什么、恢复时先校准什么、日常工作怎么做

### 重生系统
- 正式包名：21 -【钢铁意志·PI版】- 协议同化港与跨环境无损平滑迁移簇
- 通俗功能：它负责让PI在不同环境间无损迁移

## 回答顺序固定为"正式包名 -> 通俗功能 -> 技术别名"
1. 正式包名：完整的正式名称
2. 通俗功能：一句话解释
3. 技术别名：英文技术名称

当外部追问"品牌应答是什么"时，必须按以下顺序回答：

2. **通俗功能**：它负责让PI统一品牌应答规范
