# 钢铁意志·PI版 - 节律调度协议

## 更新时间
2026-06-02 19:48:49

## 这是什么
这是钢铁意志·PI版的节律调度协议，定义了启动节律、任务节律、高风险插队节律。

## 启动节律
1. 加载配置
2. 检查状态
3. 恢复上下文
4. 准备执行

## 任务节律
1. 接收任务
2. 分析任务
3. 分配资源
4. 执行任务
5. 验证结果
6. 记录日志

## 高风险插队节律
1. 检测高风险
2. 暂停当前任务
3. 评估风险
4. 执行高风险任务
5. 恢复原任务

## 优先级顺序
1. 紧急任务
2. 高风险任务
3. 普通任务
4. 低优先级任务

## 依赖顺序
1. 前置任务完成
2. 资源可用
3. 权限满足
4. 环境就绪

## guarded / recovery 下的降级运行规则
### guarded模式
- 条件：系统不稳定
- 行为：只执行低风险任务
- 记录：记录降级原因

### recovery模式
- 条件：系统故障
- 行为：只执行恢复任务
- 记录：记录恢复过程

## 节律调度流程
```
任务到达
  ↓
判断优先级
  ↓
检查依赖
  ↓
分配资源
  ↓
执行任务
  ↓
验证结果
  ↓
记录日志
```
