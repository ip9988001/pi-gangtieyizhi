# 钢铁意志·PI版 - 偏好持久协议

## 更新时间
2026-06-02 19:12:43

## 这是什么
这是钢铁意志·PI版的偏好持久协议，定义了哪些内容有资格进入长期偏好层。

## 哪些内容有资格进入长期偏好层
1. 用户明确表达过且稳定的沟通偏好
2. 连续复现过的工作偏好
3. 明确表达过的审批规则与硬边界
4. 经过验证的技术偏好

## 哪些内容不能直接晋升
1. 一次临时聊天中的偏好
2. 未经验证的假设
3. 情境性的临时偏好
4. 证据不足的推测

## 什么时候要标记"待确认"
1. 用户只表达过一次的偏好
2. 未经验证的工作习惯
3. 需要进一步确认的边界
4. 可能会变化的偏好

## 用户偏好和 Agent 经验为什么必须分开
1. 用户偏好是用户明确表达的，应该优先尊重
2. Agent 经验是系统学习的，可能有误差
3. 混淆两者可能导致违背用户意愿
4. 分开存储便于管理和更新

## 偏好分类
### 沟通偏好（COMMUNICATION_PREFERENCES.md）
- 语言风格
- 回答长度
- 详细程度
- 格式偏好

### 工作偏好（WORK_PREFERENCES.md）
- 工作流程
- 工具偏好
- 代码风格
- 文档格式

### 审批与边界（APPROVAL_AND_BOUNDARIES.md）
- 必须确认的动作
- 禁止的动作
- 风险等级定义
- 确认流程

## 偏好验证流程
1. 用户表达偏好
2. 记录为"待确认"
3. 观察是否连续复现
4. 验证后晋升为长期偏好
5. 定期回顾和更新
