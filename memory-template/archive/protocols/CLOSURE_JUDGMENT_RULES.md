# 钢铁意志·PI版 - 闭环判断规则

## 更新时间
2026-06-02 19:27:56

## 这是什么
这是钢铁意志·PI版的闭环判断规则，定义了什么叫闭环成立，什么叫闭环未成立。

## 什么叫闭环成立
1. 问题已解决
2. 目标已达成
3. 经验已提炼
4. 知识已沉淀
5. 可以复用

## 什么叫闭环未成立
1. 问题未解决
2. 目标未达成
3. 经验未提炼
4. 知识未沉淀
5. 无法复用

## keep_in_l2 最小口径
- 条件：信息不完整，需要进一步观察
- 动作：保留在L2候选池
- 状态：candidate

## promote_to_l3 最小口径
- 条件：信息完整，经过验证，值得长期保留
- 动作：晋升到L3长期记忆
- 状态：promoted

## promote_to_reusable_flow 最小口径
- 条件：经验已接近可复用流程
- 动作：标记为可复用流程候选
- 状态：promotable

## route_to_12 最小口径
- 条件：属于失败经验
- 动作：转交到12包（失败经验隔离沙箱）
- 状态：rejected

## route_to_13 最小口径
- 条件：存在冲突
- 动作：转交到13包（冲突裁决）
- 状态：conflict

## drop_as_noise 最小口径
- 条件：信息无价值，只是噪音
- 动作：丢弃
- 状态：rejected

## 闭环判断流程
```
候选条目
  ↓
判断是否闭环
  ├─ 是 → 判断去向
  │   ├─ promote_to_l3
  │   ├─ promote_to_reusable_flow
  │   ├─ route_to_12
  │   └─ route_to_13
  └─ 否 → keep_in_l2
  ↓
执行去向
  ↓
更新状态
```
