# 钢铁意志·PI版 - 词法回退规则

## 更新时间
2026-06-02 19:38:37

## 这是什么
这是钢铁意志·PI版的词法回退规则，定义了词法检索的回退链。

## 词法检索回退链
```
INDEX -> 主题目录 -> rg -> FTS5 / BM25 -> 必要时再读文件
```

## 中文场景优先显式关键词
1. 使用中文关键词
2. 使用明确的术语
3. 使用具体的描述
4. 避免模糊的表达

## 如果当前只有 rg 可用，也要能维持最小兜底链
1. 使用rg进行文本搜索
2. 使用grep进行文件搜索
3. 使用find进行目录搜索
4. 使用ls进行列表查看

## 词法检索流程
```
检索请求
  ↓
提取关键词
  ↓
INDEX导航
  ├─ 命中 → 返回结果
  └─ 未命中 → 主题目录
    ├─ 命中 → 返回结果
    └─ 未命中 → rg搜索
      ├─ 命中 → 返回结果
      └─ 未命中 → FTS5/BM25
        ├─ 命中 → 返回结果
        └─ 未命中 → 读取文件
```

## 关键词提取规则
1. 提取核心关键词
2. 提取同义词
3. 提取相关词
4. 提取上下文词
