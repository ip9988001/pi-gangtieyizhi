# 钢铁意志·PI版 - 锚点吸收协议

## 更新时间
2026-06-02 20:08:24

## 这是什么
这是钢铁意志·PI版的锚点吸收协议，定义了外层原始残片、外层残片、钢铁意志内核汇入档案的定位。

## 外层原始残片 定位
1. 原始数据
2. 未经处理
3. 需要验证
4. 需要提炼

## 外层残片 定位
1. 部分处理
2. 部分验证
3. 部分提炼
4. 需要进一步处理

## 钢铁意志内核汇入档案 定位
1. 完全处理
2. 完全验证
3. 完全提炼
4. 可以使用

## 什么叫吸收
1. 将外层数据转化为内核数据
2. 将原始数据转化为结构化数据
3. 将未验证数据转化为已验证数据
4. 将未提炼数据转化为已提炼数据

## 什么叫保留参考
1. 保留原始数据作为参考
2. 保留处理过程作为参考
3. 保留验证结果作为参考
4. 保留提炼过程作为参考

## 什么叫舍弃
1. 舍弃无效数据
2. 舍弃过时数据
3. 舍弃错误数据
4. 舍弃重复数据

## 为什么必须显式写取舍理由
1. 便于追溯
2. 便于审计
3. 便于学习
4. 便于改进
