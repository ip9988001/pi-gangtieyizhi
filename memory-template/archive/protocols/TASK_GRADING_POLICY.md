# 钢铁意志·PI版 - 任务分级策略

## 更新时间
2026-06-02 19:48:49

## 这是什么
这是钢铁意志·PI版的任务分级策略，定义了L0-L3的复杂度语义和G0-G3的风险语义。

## L0-L3 的复杂度语义
### L0：简单任务
- 特征：步骤少、风险低、时间短
- 示例：查看状态、读取文件
- 流程：直接执行

### L1：普通任务
- 特征：步骤适中、风险适中、时间适中
- 示例：创建文件、更新配置
- 流程：标准流程

### L2：复杂任务
- 特征：步骤多、风险高、时间长
- 示例：部署系统、重构代码
- 流程：详细规划

### L3：超复杂任务
- 特征：步骤很多、风险很高、时间很长
- 示例：架构设计、系统迁移
- 流程：分阶段执行

## G0-G3 的风险语义
### G0：无风险
- 特征：不影响系统、可逆、可恢复
- 示例：查看信息、搜索内容
- 处理：直接执行

### G1：低风险
- 特征：影响有限、可逆、可恢复
- 示例：创建文件、更新配置
- 处理：提示确认

### G2：中风险
- 特征：影响较大、部分可逆、部分可恢复
- 示例：删除文件、修改系统
- 处理：强制确认

### G3：高风险
- 特征：影响很大、不可逆、不可恢复
- 示例：格式化磁盘、删除数据库
- 处理：双重确认

## 不同等级分别该走哪条最小流程
### L0+G0
- 流程：直接执行
- 记录：操作日志

### L1+G1
- 流程：标准流程
- 记录：操作日志 + 状态更新

### L2+G2
- 流程：详细规划
- 记录：操作日志 + 状态更新 + 风险评估

### L3+G3
- 流程：分阶段执行
- 记录：操作日志 + 状态更新 + 风险评估 + 治理审计

## 何时允许快路径，何时必须回慢链
### 允许快路径
1. L0+G0任务
2. 紧急修复任务
3. 用户明确要求

### 必须回慢链
1. L2+G2任务
2. L3+G3任务
3. 涉及系统核心的任务
