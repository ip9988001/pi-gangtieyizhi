# Recall结果呈现样式规范

## 结果呈现定义

结果呈现样式规范定义了recall结果返回给用户时应包含的字段和格式。

## 最小字段要求

### 必填字段
1. **title** (标题)
   - 说明: 条目的简短标题
   - 示例: "重启铁律"

2. **path** (路径)
   - 说明: 条目的文件路径
   - 示例: "~/.pi/agent/memory/lessons/night-restart-lesson.md"

3. **summary** (摘要)
   - 说明: 条目的简短摘要
   - 示例: "永远不要在半夜2点后执行微服务重启"

4. **state** (状态)
   - 说明: 条目的当前状态
   - 示例: "active"

5. **freshness** (新鲜度)
   - 说明: 条目的新鲜程度
   - 示例: "fresh"

6. **read_hint** (读取提示)
   - 说明: 读取该条目时的提示信息
   - 示例: "运维人员必读，避免夜间操作事故"

7. **anchor_refs** (锚点引用)
   - 说明: 条目的来源锚点
   - 示例: ["agent/lessons/night-restart-lesson.md"]

8. **match_reason** (匹配原因)
   - 说明: 为什么该条目匹配查询
   - 示例: "包含关键词'重启'"

### 可选字段
- **confidence**: 置信度
- **last_verified**: 最后验证时间
- **access_count**: 访问次数
- **weight**: 排序权重

## 呈现场景

### 场景1: 只给摘要和路径
- **条件**: 查询简单，或结果较多
- **格式**: 只展示title、path、summary
- **说明**: 快速浏览，不需要详细信息

### 场景2: 完整信息
- **条件**: 查询复杂，或用户需要详细信息
- **格式**: 展示所有必填字段
- **说明**: 提供完整信息，便于决策

### 场景3: 提示风险或降权
- **条件**: 结果有风险或被降权
- **格式**: 在结果中明确标注风险或降权原因
- **说明**: 提醒用户注意风险

## 呈现格式

### 标准格式
```
## Recall结果

### 结果1: [title]
- **路径**: [path]
- **摘要**: [summary]
- **状态**: [state]
- **新鲜度**: [freshness]
- **读取提示**: [read_hint]
- **锚点**: [anchor_refs]
- **匹配原因**: [match_reason]
```

### 简化格式
```
## Recall结果

1. [title] - [summary] ([path])
2. [title] - [summary] ([path])
```

## 呈现与预算联动

### R0预算
- **格式**: 简化格式
- **字段**: title、path、summary
- **说明**: 快速浏览

### R1预算
- **格式**: 标准格式
- **字段**: 所有必填字段
- **说明**: 提供完整信息

### R2预算
- **格式**: 标准格式 + 额外字段
- **字段**: 所有必填字段 + 可选字段
- **说明**: 提供详细信息

## 注意事项

1. **不要整篇正文塞进上下文**: 只返回必要字段
2. **与预算联动**: 呈现格式与读取预算对应
3. **记录呈现**: 所有呈现应记录，便于追溯
