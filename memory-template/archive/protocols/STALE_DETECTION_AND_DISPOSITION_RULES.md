# 钢铁意志·PI版 - 过时检测规则

## 更新时间
2026-06-02 19:34:57

## 这是什么
这是钢铁意志·PI版的过时检测规则，定义了如何检测和处理过时内容。

## 过时定义
当内容不再适用或不再准确时，就产生了过时。

## 过时检测标准
1. 时间过时：内容创建时间过长
2. 来源过时：内容来源不再有效
3. 状态过时：内容状态不再适用
4. 环境过时：内容环境不再适用

## 最低证据要求
1. 必须有创建时间
2. 必须有最后验证时间
3. 必须有来源引用
4. 必须有状态标记

## 必须保留的字段
1. 过时ID
2. 内容ID
3. 过时原因
4. 过时时间
5. 过时状态
6. 处理动作

## 什么时候可以标记为过时
1. 内容创建时间超过阈值
2. 内容来源不再有效
3. 内容状态不再适用
4. 内容环境不再适用

## 什么时候不能标记为过时
1. 内容仍然适用
2. 内容来源仍然有效
3. 内容状态仍然适用
4. 内容环境仍然适用

## 过时处理流程
```
过时检测
  ↓
判断是否过时
  ├─ 是 → 标记过时
  └─ 否 → 保持原状
  ↓
执行处理
  ↓
更新状态
```
