# 钢铁意志·PI版 - 候选状态规则

## 更新时间
2026-06-02 19:21:35

## 这是什么
这是钢铁意志·PI版的候选状态规则，定义了候选条目的各种状态。

## partial
- 含义：部分信息，需要补充
- 条件：信息不完整，需要进一步确认
- 操作：补充信息，等待确认

## candidate
- 含义：候选条目，等待筛选
- 条件：信息完整，等待进一步筛选
- 操作：等待Heartbeat筛选

## promotable
- 含义：可晋升，等待晋升
- 条件：信息验证通过，可以晋升到L3
- 操作：等待晋升操作

## rejected
- 含义：已拒绝，不保留
- 条件：信息验证失败，不值得保留
- 操作：移动到.archive/

## superseded
- 含义：已被替代，不再活跃
- 条件：有更新的信息替代
- 操作：移动到.archive/

## promoted
- 含义：已晋升，已进入L3
- 条件：已成功晋升到L3
- 操作：保留在candidates/，标记为promoted

## 状态转换流程
```
partial
  ↓
candidate
  ↓
promotable / rejected / superseded
  ↓
promoted（如果promotable）
```

## 状态更新规则
1. 状态只能向前转换，不能向后
2. 状态更新必须记录时间
3. 状态更新必须记录原因
4. 状态更新必须保留历史
