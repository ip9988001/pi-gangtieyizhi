# 钢铁意志·PI版 - 记忆域策略

## 更新时间
2026-06-02 19:18:37

## 这是什么
这是钢铁意志·PI版的记忆域策略，定义了User Memory和Agent Memory的职责划分。

## User Memory 负责什么
1. 用户明确表达的偏好
2. 用户的沟通风格
3. 用户的工作习惯
4. 用户的审批规则
5. 用户的边界控制
6. 用户的个人信息

## Agent Memory 负责什么
1. 系统决策记录
2. 失败教训
3. 成功案例
4. 工作模式
5. 项目状态
6. 系统反思
7. 操作日志

## 为什么偏好、边界、用户事件属于用户域
1. 这些是用户明确表达的
2. 这些应该优先尊重用户意愿
3. 这些可能会随用户变化而变化
4. 这些需要用户确认才能修改

## 为什么决策、教训、案例、模式、项目状态属于 Agent 域
1. 这些是系统学习的
2. 这些是系统运行产生的
3. 这些可以自动更新
4. 这些是系统经验的积累

## 域划分原则
1. 用户域：用户说了算
2. Agent域：系统说了算
3. 不混写：用户偏好不写入Agent域
4. 不混淆：系统经验不写入用户域
