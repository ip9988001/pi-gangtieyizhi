# 钢铁意志·PI版 - 语义检索策略

## 更新时间
2026-06-02 19:42:15

## 这是什么
这是钢铁意志·PI版的语义检索策略，定义了S3语义增强层的正式定位。

## S3 的正式定位
1. S3是语义增强层，不是默认主路
2. S3是S1和S2的补充，不是替代
3. S3提供语义匹配能力
4. S3需要QMD或类似技术支持

## S3 负责什么
1. 语义相似度匹配
2. 向量搜索
3. 语义推荐
4. 智能联想

## S3 不负责什么
1. 不负责精确匹配
2. 不负责关键词搜索
3. 不负责目录导航
4. 不负责结构化查询

## 默认顺序固定为 S1 -> S2 -> S3
1. 先尝试S1导航检索
2. 如果S1找不到，尝试S2词法检索
3. 如果S2找不到，尝试S3语义检索
4. 如果S3找不到，提示用户

## 什么时候用 hybrid
1. 需要同时考虑关键词和语义
2. 查询比较复杂
3. 需要高精度结果
4. 有足够的时间和资源

## 什么时候用 keyword
1. 查询比较简单
2. 有明确的关键词
3. 需要快速结果
4. 资源有限

## 什么时候用 vsearch
1. 需要向量搜索
2. 查询比较模糊
3. 需要语义匹配
4. 有向量索引

## 语义检索流程
```
检索请求
  ↓
S1导航检索
  ├─ 命中 → 返回结果
  └─ 未命中 → S2词法检索
    ├─ 命中 → 返回结果
    └─ 未命中 → S3语义检索
      ├─ 命中 → 返回结果
      └─ 未命中 → 提示用户
```
