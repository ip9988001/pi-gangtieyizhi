# 钢铁意志·PI版 - 迁移烟雾测试规则

## 更新时间
2026-06-02 20:03:25

## 这是什么
这是钢铁意志·PI版的迁移烟雾测试规则，定义了旧实例快照范围、新实例恢复顺序、smoke test项。

## 旧实例快照范围
1. 记忆文件
2. 系统文件
3. 配置文件
4. 审计日志

## 新实例恢复顺序
1. 恢复记忆文件
2. 恢复系统文件
3. 恢复配置文件
4. 验证恢复结果

## smoke test 项
1. 文件完整性检查
2. 配置正确性检查
3. 服务可用性检查
4. 功能正常性检查

## Pass / Partial / Fail 的迁移口径
### Pass
- 所有文件恢复成功
- 所有配置正确
- 所有服务正常
- 所有功能正常

### Partial
- 部分文件恢复成功
- 部分配置正确
- 部分服务正常
- 部分功能正常

### Fail
- 关键文件恢复失败
- 关键配置错误
- 关键服务异常
- 关键功能失败

## 迁移流程
```
准备迁移
  ↓
创建旧实例快照
  ↓
复制到新实例
  ↓
恢复新实例
  ↓
执行smoke test
  ↓
判断Pass/Partial/Fail
  ├─ Pass → 迁移成功
  ├─ Partial → 部分成功
  └─ Fail → 迁移失败
  ↓
记录迁移结果
```
