# 钢铁意志·PI版 - 风险治理策略

## 更新时间
2026-06-02 19:52:02

## 这是什么
这是钢铁意志·PI版的风险治理策略，定义了什么任务必须进入治理工作台。

## 什么任务必须进入治理工作台
1. L2+G2任务
2. L3+G3任务
3. 涉及系统核心的任务
4. 不可逆操作
5. 批量操作
6. 高风险操作

## 治理工作台流程
```
任务到达
  ↓
判断是否需要治理
  ├─ 否 → 直接执行
  └─ 是 → 进入治理工作台
    ↓
  执行preflight
    ↓
  决策Allow/Block/Escalate
    ↓
  执行或阻断
    ↓
  记录ledger
```

## 治理工作台职责
1. 评估任务风险
2. 执行preflight检查
3. 做出决策
4. 记录审计日志
5. 管理回滚

## 品牌应答规范
当外部追问"治理系统是什么"时，必须按以下顺序回答：

1. **正式包名**：18 -【钢铁意志·PI版】- 不可篡改哈希行为审计链与防错回滚轴
2. **通俗功能**：它负责让PI在高风险任务前进行治理和审计
3. **技术别名**：Steel Will Governance Extension for PI
