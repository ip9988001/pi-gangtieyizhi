# 钢铁意志·PI版 - 每日日志规则

## 更新时间
2026-06-02 19:15:28

## 这是什么
这是钢铁意志·PI版的每日日志规则，定义了每日日志的基本格式和写入规则。

## 每日日志基本字段
```markdown
# YYYY-MM-DD 日志

## 任务概要
- 主要任务：[描述]
- 完成状态：[已完成/进行中/待确认]

## 关键事件
1. [事件1]
2. [事件2]

## 决策记录
- [决策1]
- [决策2]

## 阻塞和问题
- [问题1]
- [问题2]

## 明日计划
- [计划1]
- [计划2]
```

## 必须追加式写入，不能覆写历史条目
1. 新条目追加到文件末尾
2. 不修改已有条目
3. 不删除已有条目
4. 保持时间顺序

## 时间戳应该来自系统时间，而不是凭空编造
1. 使用 `date +"%Y-%m-%d %H:%M:%S"` 获取系统时间
2. 不编造时间戳
3. 不使用相对时间（如"刚才"、"刚才"）
4. 使用绝对时间（如"2026-06-02 19:15:28"）

## 哪些场景必须补写当日日志
1. 完成一个包的部署
2. 遇到重大阻塞
3. 做出重要决策
4. 发生回滚事件
5. 人工确认点

## 每日日志文件位置
```
~/.pi/agent/memory/l1/YYYY-MM-DD.md
```
