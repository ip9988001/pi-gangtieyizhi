# 钢铁意志·PI版 - 未回写规则

## 更新时间
2026-06-02 19:34:57

## 这是什么
这是钢铁意志·PI版的未回写规则，定义了如何处理未回写的内容。

## 未回写定义
当内容应该回写但没有回写时，就产生了未回写。

## 未回写检测标准
1. 时间未回写：内容应该回写但没有回写
2. 状态未回写：内容状态应该更新但没有更新
3. 来源未回写：内容来源应该记录但没有记录
4. 动作未回写：内容动作应该执行但没有执行

## 最低证据要求
1. 必须有应该回写的时间
2. 必须有实际回写的时间
3. 必须有未回写的原因
4. 必须有未回写的影响

## 必须保留的字段
1. 未回写ID
2. 内容ID
3. 应该回写时间
4. 实际回写时间
5. 未回写原因
6. 未回写影响

## 什么时候可以标记为未回写
1. 内容应该回写但没有回写
2. 内容状态应该更新但没有更新
3. 内容来源应该记录但没有记录
4. 内容动作应该执行但没有执行

## 什么时候不能标记为未回写
1. 内容已经回写
2. 内容状态已经更新
3. 内容来源已经记录
4. 内容动作已经执行

## 未回写处理流程
```
未回写检测
  ↓
判断是否未回写
  ├─ 是 → 标记未回写
  └─ 否 → 保持原状
  ↓
执行处理
  ↓
更新状态
```
