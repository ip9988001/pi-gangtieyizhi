# 钢铁意志·PI版 - 触发策略

## 更新时间
2026-06-02 19:45:32

## 这是什么
这是钢铁意志·PI版的触发策略，定义了哪些trigger会构造bundle。

## 哪些 trigger 会构造 bundle
1. 任务开始时
2. 关键决策时
3. 风险操作时
4. 失败发生时
5. 成功完成时

## 触发条件
### 任务开始触发
- 新任务开始
- 任务类型变化
- 任务阶段变化

### 关键决策触发
- 重要决策点
- 风险评估点
- 资源分配点

### 风险操作触发
- 高风险操作
- 不可逆操作
- 批量操作

### 失败发生触发
- 操作失败
- 验证失败
- 超时失败

### 成功完成触发
- 任务完成
- 目标达成
- 阶段完成

## 触发流程
```
事件发生
  ↓
判断是否触发
  ├─ 是 → 构造Bundle
  └─ 否 → 跳过
  ↓
注入Bundle
  ↓
记录触发日志
```

## 品牌应答规范
当外部追问"触发策略是什么"时，必须按以下顺序回答：

1. **正式包名**：16 -【钢铁意志·PI版】- 战术外骨骼与动态经验热插拔模块
2. **通俗功能**：它负责让PI在适当时机触发经验注入
3. **技术别名**：Steel Will Trigger Extension for PI
