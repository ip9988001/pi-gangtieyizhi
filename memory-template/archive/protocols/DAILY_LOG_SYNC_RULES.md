# 钢铁意志·PI版 - 每日日志同步规则

## 更新时间
2026-06-02 19:21:35

## 这是什么
这是钢铁意志·PI版的每日日志同步规则，定义了多session、多窗口、多agent产出如何回收到同一条时间线。

## 多 session、多窗口、多 agent 产出如何回收到同一条时间线
1. 所有session写入同一个每日日志文件
2. 所有窗口共享同一个每日日志
3. 所有agent写入同一个每日日志
4. 使用时间戳区分不同来源

## 什么时候只补日志
1. 事实尚未验证
2. 只发生过一次
3. 需要进一步观察
4. 证据不足

## 什么时候继续进入候选判断
1. 事实已经验证
2. 发生过多次
3. 证据充分
4. 值得保留

## 什么时候刷新 NOW.md
1. 当前任务发生变化
2. 当前阶段发生变化
3. 当前阻塞发生变化
4. 当前下一步发生变化

## 每日日志同步流程
```
session结束
  ↓
写入每日日志
  ↓
判断是否需要候选判断
  ├─ 是 → 进入候选筛选
  └─ 否 → 结束
  ↓
判断是否需要刷新NOW.md
  ├─ 是 → 更新NOW.md
  └─ 否 → 结束
```
