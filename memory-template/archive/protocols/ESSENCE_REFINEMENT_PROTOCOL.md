# 钢铁意志·PI版 - 精华提炼协议

## 更新时间
2026-06-02 19:27:56

## 这是什么
这是钢铁意志·PI版的精华提炼协议，定义了Nightly Reflection要提取哪些精华字段。

## Nightly Reflection 要提取哪些精华字段
1. 锚点（anchor_refs）：原始来源引用
2. 精华内容（essence）：提炼后的核心信息
3. 类型（type）：决策/教训/案例/模式
4. 域（domain）：user/agent
5. 状态（status）：partial/candidate/promotable
6. 关键词（keywords）：便于检索

## 什么属于结构化提炼
1. 有明确的字段定义
2. 有明确的格式要求
3. 有明确的来源引用
4. 有明确的状态标记

## 什么只是原文复述
1. 没有提炼，只是复制
2. 没有结构，只是段落
3. 没有来源，只是描述
4. 没有状态，只是陈述

## 为什么必须保留 anchor_refs
1. 可追溯：可以追溯到原始来源
2. 可验证：可以验证信息的准确性
3. 可更新：可以在原始来源更新时同步更新
4. 可审计：可以审计信息的来源和变化

## 精华提炼流程
```
原始内容
  ↓
提取关键信息
  ↓
结构化整理
  ↓
添加元数据
  ↓
保留anchor_refs
  ↓
生成精华条目
```

## 精华条目格式
```markdown
# [标题]

## 元数据
- 锚点：[anchor_refs]
- 类型：[决策/教训/案例/模式]
- 域：[user/agent]
- 状态：[partial/candidate/promotable]
- 关键词：[关键词1, 关键词2]

## 精华内容
[提炼后的核心信息]

## 来源
- 原始来源：[来源]
- 提炼时间：[时间]
```
