# 钢铁意志·PI版 - L2候选池规则

## 更新时间
2026-06-02 19:21:35

## 这是什么
这是钢铁意志·PI版的L2候选池规则，定义了什么适合进入L2，什么只留日志。

## 什么适合进入 L2
1. 事实已经验证
2. 发生过多次
3. 证据充分
4. 值得保留
5. 有明确的来源

## 什么只留日志
1. 事实尚未验证
2. 只发生过一次
3. 需要进一步观察
4. 证据不足
5. 来源不明确

## user / agent 分流规则
### user 域
1. 用户明确表达的偏好
2. 用户的沟通风格
3. 用户的工作习惯
4. 用户的审批规则
5. 用户的边界控制

### agent 域
1. 系统决策记录
2. 失败教训
3. 成功案例
4. 工作模式
5. 项目状态

## 候选池目录结构
```
memory/candidates/
├── user/             # 用户相关候选
│   └── *.md          # 候选条目
└── agent/            # Agent相关候选
    └── *.md          # 候选条目
```
