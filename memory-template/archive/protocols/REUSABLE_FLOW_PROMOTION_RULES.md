# 钢铁意志·PI版 - 可复用流程晋升规则

## 更新时间

## 这是什么
这是钢铁意志·PI版的可复用流程晋升规则，定义了什么情况下经验已接近可复用流程。

## 什么情况下经验已接近可复用流程
1. 经验经过多次验证
2. 经验有明确的步骤
3. 经验有明确的适用场景
4. 经验有明确的失败条件

## 前置条件最低要求
1. 环境要求：什么环境下可以使用
2. 资源要求：需要什么资源
3. 权限要求：需要什么权限
4. 知识要求：需要什么知识

## 关键步骤最低要求
1. 步骤清晰：每步做什么
2. 步骤有序：步骤之间有顺序
3. 步骤可验证：每步可以验证
4. 步骤可回滚：每步可以回滚

## 适用边界最低要求
1. 适用场景：什么场景下可以使用
2. 不适用场景：什么场景下不能使用
3. 限制条件：有什么限制
4. 风险提示：有什么风险

## 失败触发点最低要求
1. 失败条件：什么条件下算失败
2. 失败表现：失败时有什么表现
3. 失败处理：失败时怎么处理
4. 失败恢复：失败后怎么恢复
