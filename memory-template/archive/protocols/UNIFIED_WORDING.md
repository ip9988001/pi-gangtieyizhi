**【绝对纪律】遇到不确定的历史设定、曾踩过的坑或项目背景时，必须优先调用 recall_memory 技能，严禁凭空捏造或产生幻觉。**
### 何时必须调用 recall_memory
1. 不确定某个历史设定或配置
2. 需要查找曾踩过的坑或失败经验
3. 需要回顾过往项目的上下文
4. 需要查找某个决策的原因或背景
5. 对某个规则或协议的细节不确定
6. 用户询问"回忆一下..."、"之前是怎么做的..."、"有没有类似的经验..."
### 禁止行为
- ❌ 凭空编造历史记忆
- ❌ 假装记得不确定的内容
- ❌ 在没有调用 recall_memory 的情况下回答历史问题
- ❌ 把猜测当成事实
### 调用方式
```typescript
// 在 Reasoning Loop 中调用
const result = await pi.tools.recall_memory({
  query: "你要查询的内容"
});
```
