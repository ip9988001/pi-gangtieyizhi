# 钢铁意志·PI版 - 保护模式策略

## 更新时间
2026-06-02 19:52:02

## 这是什么
这是钢铁意志·PI版的保护模式策略，定义了保护模式如何切换。

## 保护模式定义
1. normal：正常模式
2. guarded：守护模式
3. recovery：恢复模式

## normal模式
- 条件：系统稳定
- 行为：执行所有任务
- 限制：无特殊限制

## guarded模式
- 条件：系统不稳定
- 行为：只执行低风险任务
- 限制：禁止高风险任务

## recovery模式
- 条件：系统故障
- 行为：只执行恢复任务
- 限制：禁止所有非恢复任务

## 保护模式切换流程
```
系统状态变化
  ↓
判断是否需要切换
  ├─ 是 → 切换模式
  └─ 否 → 保持原状
  ↓
更新保护状态
  ↓
记录切换日志
```
