# 钢铁意志·PI版 - 检索层策略

## 更新时间
2026-06-02 19:38:37

## 这是什么
这是钢铁意志·PI版的检索层策略，定义了检索的层次和默认顺序。

## S1 是导航检索
1. 通过INDEX导航
2. 通过目录结构导航
3. 通过关键文件导航
4. 通过运行面导航

## S2 是词法检索
1. 通过grep搜索
2. 通过rg搜索
3. 通过FTS5搜索
4. 通过BM25搜索

## S3 是语义增强层
1. 通过QMD语义搜索
2. 通过向量搜索
3. 通过语义匹配
4. 通过智能推荐

## 默认顺序固定为 S1 -> S2 -> S3
1. 先尝试S1导航检索
2. 如果S1找不到，尝试S2词法检索
3. 如果S2找不到，尝试S3语义检索
4. 如果S3找不到，提示用户

## 检索命中后先看 R0，再决定是否展开到 R1 / R2
1. R0：摘要信息
2. R1：详细信息
3. R2：完整信息

## 检索流程
```
检索请求
  ↓
S1导航检索
  ├─ 命中 → 返回R0
  └─ 未命中 → S2词法检索
    ├─ 命中 → 返回R0
    └─ 未命中 → S3语义检索
      ├─ 命中 → 返回R0
      └─ 未命中 → 提示用户
  ↓
判断是否需要展开
  ├─ 是 → 返回R1/R2
  └─ 否 → 返回R0
```
