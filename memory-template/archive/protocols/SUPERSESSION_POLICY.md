# 钢铁意志·PI版 - 替代策略

## 更新时间
2026-06-02 19:34:57

## 这是什么
这是钢铁意志·PI版的替代策略，定义了如何处理内容替代。

## 替代定义
当新内容完全替代旧内容时，就产生了替代关系。

## 最低证据要求
1. 新内容必须经过验证
2. 新内容必须有明确来源
3. 新内容必须有时间标记
4. 新内容必须有替代理由

## 必须保留的字段
1. 替代ID
2. 原内容ID
3. 新内容ID
4. 替代理由
5. 替代时间
6. 替代状态

## 什么时候可以替代
1. 新内容经过验证
2. 新内容有明确来源
3. 新内容有替代理由
4. 新内容有时间标记

## 什么时候不能替代
1. 新内容未经验证
2. 新内容来源不明确
3. 新内容没有替代理由
4. 新内容没有时间标记

## 为什么不能直接删除旧内容
1. 旧内容可能有历史价值
2. 旧内容可能有参考价值
3. 旧内容可能有追溯价值
4. 旧内容可能有审计价值

## 替代流程
```
新内容出现
  ↓
判断是否需要替代
  ├─ 是 → 执行替代
  └─ 否 → 保留原内容
  ↓
更新状态
  ↓
记录替代结果
```
