# 钢铁意志·PI版 - 边界读取规则

## 更新时间
2026-06-02 19:12:43

## 这是什么
这是钢铁意志·PI版的边界读取规则，定义了哪些动作执行前必须先读边界层。

## 哪些动作执行前必须先读边界层
1. 批量修改文件
2. 删除文件或目录
3. 覆盖重要文件
4. 自动外发内容
5. 执行不可逆操作
6. 修改系统配置
7. 访问敏感数据

## 不可逆动作默认先确认
1. 删除文件
2. 覆盖重要文件
3. 修改系统配置
4. 批量操作
5. 外发敏感内容

## 批量修改、删除、覆盖、自动外发前的最低确认口径
1. 明确操作范围
2. 明确影响的文件
3. 明确操作的不可逆性
4. 获得用户明确确认
5. 记录操作日志

## 哪些边界不能只留在会话里
1. 用户明确表达的禁止事项
2. 必须确认的操作类型
3. 风险等级定义
4. 审批流程规则

## 边界读取流程
```
高风险操作
  ↓
读取 BOUNDARY_READ_RULES.md
  ↓
读取 APPROVAL_AND_BOUNDARIES.md
  ↓
判断操作风险等级
  ├─ 低风险 → 执行并记录
  ├─ 中风险 → 提示确认
  └─ 高风险 → 强制确认
  ↓
执行操作
  ↓
记录操作日志
```

## 风险等级定义
### 低风险
- 读取文件
- 查看状态
- 搜索内容

### 中风险
- 创建新文件
- 修改非关键文件
- 执行常规命令

### 高风险
- 删除文件
- 覆盖重要文件
- 修改系统配置
- 批量操作
- 外发敏感内容
