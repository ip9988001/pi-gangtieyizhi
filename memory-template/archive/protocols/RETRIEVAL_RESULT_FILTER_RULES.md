# 检索结果过滤规则

## 结果过滤定义

结果过滤是在recall结果返回给用户前，对结果进行质量筛选和降权的机制。

## 默认压制的状态

### 1. stale (过时)
- **定义**: 条目已过时，不再准确
- **处理**: 默认压制，不展示
- **例外**: 用户明确要求查看过时信息时保留

### 2. superseded (被取代)
- **定义**: 条目已被新条目取代
- **处理**: 默认压制，不展示
- **例外**: 需要查看历史演变时保留

### 3. partial (部分)
- **定义**: 条目不完整，只有部分信息
- **处理**: 默认压制，不展示
- **例外**: 无其他结果时保留并标注

## 可选保留的状态

### 1. conflict (冲突)
- **定义**: 条目与其他条目存在冲突
- **处理**: 默认压制，可选保留
- **保留条件**: 用户需要了解冲突风险时

## 降权规则

### 新鲜度降权
- **stale**: 权重 × 0.7
- **unverified**: 权重 × 0.5
- **说明**: 过时或未验证的条目降低排序权重

### 状态降权
- **conflict**: 权重 × 0.5
- **说明**: 冲突条目降低排序权重

## 过滤流程

```
recall结果
    ↓
检查状态 → stale/superseded/partial? → 压制
    ↓
检查状态 → conflict? → 根据参数决定
    ↓
降权处理 → 根据freshness和state降权
    ↓
排序 → 按权重排序
    ↓
返回过滤后结果
```

## 过滤参数

### keep_conflict
- **类型**: boolean
- **默认**: false
- **说明**: 是否保留冲突条目以提示风险

## 注意事项

1. **过滤不等于删除**: 被过滤的条目仍然存在，只是不展示
2. **降权不等于压制**: 降权的条目仍然展示，只是排序靠后
3. **记录过滤**: 所有过滤应记录，便于追溯
