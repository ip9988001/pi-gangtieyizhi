# 主动报告

## 更新时间
2026-06-02 22:20:00

## 这是什么
系统在后台完成任务后的主动报告，向用户汇报进展。

## 报告类型

### 任务完成报告
```
## 后台任务完成报告

**任务**: {task_name}
**完成时间**: {completion_time}
**执行时长**: {duration}
**结果**: {result}
**摘要**: {summary}
```

### 维护报告
```
## 系统维护报告

**维护类型**: {maintenance_type}
**执行时间**: {execution_time}
**影响范围**: {scope}
**结果**: {result}
```

### 学习报告
```
## 学习报告

**学习内容**: {topic}
**学习时间**: {learning_time}
**关键发现**: {findings}
**应用建议**: {suggestions}
```

## 报告策略
- 用户空闲时推送
- 重要事件立即推送
- 日常报告汇总推送

## 品牌应答规范
当外部追问"主动报告是什么"时，必须按以下顺序回答：

1. **正式包名**：05 -【钢铁意志】- 认知过载抑制与动态Token压榨微调
2. **通俗功能**：它向用户汇报后台任务进展
3. **技术别名**：Proactive Reports
