# 钢铁意志·PI版 - 运行时感知策略

## 更新时间
2026-06-02 19:59:18

## 这是什么
这是钢铁意志·PI版的运行时感知策略，定义了什么时候启用感知输入。

## 什么时候启用感知输入
1. 高风险任务执行前
2. 系统状态异常时
3. 用户主动请求时
4. 定时触发（可选）

## 感知输入类型
1. 宿主体征采样
2. 系统状态检查
3. 资源使用监控
4. 错误日志分析

## 感知流程
```
感知触发
  ↓
收集感知数据
  ↓
分析感知数据
  ↓
判断是否需要反应
  ├─ 是 → 执行反应
  └─ 否 → 记录日志
  ↓
更新感知状态
```

## 感知限制
1. 不是默认全时开启
2. 不是无边界扩张
3. 不是替代人工判断
4. 不是长期知识来源
