# 钢铁意志·PI版 - 宿主预检规则

## 更新时间
2026-06-02 19:59:18

## 这是什么
这是钢铁意志·PI版的宿主预检规则，定义了哪些任务必须前置宿主体征采样。

## 哪些任务必须前置宿主体征采样
1. 高风险任务执行前
2. 系统修改前
3. 批量操作前
4. 资源密集型任务前

## 宿主体征采样内容
1. CPU使用率
2. 内存使用率
3. 磁盘空间
4. 网络状态

## 预检流程
```
任务到达
  ↓
判断是否需要预检
  ├─ 否 → 直接执行
  └─ 是 → 执行预检
    ↓
  采样宿主体征
    ↓
  分析体征数据
    ↓
  判断是否可以执行
    ├─ 是 → 执行任务
    └─ 否 → 暂停或降级
```

## 预检阈值
- CPU使用率 > 80%：警告
- 内存使用率 > 80%：警告
- 磁盘空间 < 10%：阻断
- 网络状态异常：阻断
