# 钢铁意志·PI版 - 恢复协议

## 更新时间
2026-06-02 19:10:20

## 这是什么
这是钢铁意志·PI版的恢复协议，定义了新窗口如何恢复状态。

## 新窗口先按什么顺序恢复状态
1. 读取 `START_HERE.md` - 单一入口
2. 读取 `NEW_WINDOW_RESUME_CARD.md` - 新窗口恢复卡
3. 读取 `CONTINUITY_SNAPSHOT.md` - 连续性快照
4. 读取 `goals/current-stage.md` - 当前阶段
5. 读取 `STAGE_TRACKER.md` - 阶段跟踪

## 什么时候只需要最小续接
1. 只需要了解当前状态时
2. 只需要查看母目标时
3. 只需要确认当前阶段时

## 什么时候要扩读
1. 需要查看详细历史时
2. 需要了解具体执行步骤时
3. 需要查看回写纪律时
4. 需要了解操作流程时

## "接手理解完成"和"续接成功"如何区分
### 接手理解完成
- 已读取所有必要文件
- 已了解当前状态
- 已了解母目标
- 已了解当前阶段

### 续接成功
- 接手理解完成
- 已执行一件真实任务
- 已回写状态
- 已更新阶段跟踪

## 最少必须回写哪些状态面
1. `STAGE_TRACKER.md` - 阶段跟踪
2. `goals/current-stage.md` - 当前阶段
3. `stages/XX-包名-result.md` - 执行结果

## 恢复流程图
```
新窗口启动
  ↓
读取 START_HERE.md
  ↓
读取 NEW_WINDOW_RESUME_CARD.md
  ↓
读取 CONTINUITY_SNAPSHOT.md
  ↓
读取 goals/current-stage.md
  ↓
读取 STAGE_TRACKER.md
  ↓
判断是否需要扩读
  ├─ 是 → 读取详细文件
  └─ 否 → 继续
  ↓
执行任务
  ↓
回写状态
  ↓
续接成功
```
