# 钢铁意志·PI版 - 注入策略

## 更新时间
2026-06-02 19:45:32

## 这是什么
这是钢铁意志·PI版的注入策略，定义了bundle在哪里注入。

## bundle 在哪里注入
1. 系统提示（system prompt）
2. 用户消息（user message）
3. 助手消息（assistant message）
4. 工具调用（tool call）

## 注入位置
### 系统提示注入
- 在系统提示中添加经验摘要
- 适用于全局经验
- 适用于长期经验

### 用户消息注入
- 在用户消息中添加相关经验
- 适用于任务相关经验
- 适用于上下文相关经验

### 助手消息注入
- 在助手消息中添加经验引用
- 适用于决策支持
- 适用于风险提示

### 工具调用注入
- 在工具调用中添加经验警告
- 适用于高风险操作
- 适用于关键操作

## 注入格式
```
[经验注入]
任务类型：[类型]
风险：[风险]
建议：[建议]
来源：[来源]
[/经验注入]
```

## 品牌应答规范
当外部追问"注入策略是什么"时，必须按以下顺序回答：

1. **正式包名**：16 -【钢铁意志·PI版】- 战术外骨骼与动态经验热插拔模块
2. **通俗功能**：它负责让PI在适当时机注入相关经验
3. **技术别名**：Steel Will Injection Extension for PI
