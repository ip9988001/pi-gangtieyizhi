# 钢铁意志·PI版 - 失败晋升规则

## 更新时间
2026-06-02 19:31:29

## 这是什么
这是钢铁意志·PI版的失败晋升规则，定义了失败经验什么时候晋升到哪个层次。

## 失败经验什么时候只留在 closure 或日志
1. 失败刚刚发生
2. 失败原因不明确
3. 失败影响有限
4. 失败没有普遍性

## 什么时候进入候选层
1. 失败原因已明确
2. 失败影响已评估
3. 失败有普遍性
4. 失败有学习价值

## 什么时候进入 memory/agent/lessons/<topic>.md
1. 失败经过验证
2. 失败有明确的教训
3. 失败有明确的建议
4. 失败有普遍性

## 什么时候只转交 13 / 18
1. 失败涉及冲突（转交13）
2. 失败涉及治理（转交18）
3. 失败需要裁决（转交13）
4. 失败需要审计（转交18）

## 失败晋升流程
```
失败发生
  ↓
记录到closure或日志
  ↓
判断是否需要晋升
  ├─ 是 → 判断晋升层次
  │   ├─ 候选层
  │   ├─ lessons/
  │   └─ 转交13/18
  └─ 否 → 保留在closure或日志
  ↓
执行晋升
  ↓
更新状态
```

## 失败经验层次
### L1：原始记录
- 位置：closure或日志
- 状态：raw
- 内容：原始失败记录

### L2：候选筛选
- 位置：candidates/agent/lessons/
- 状态：candidate
- 内容：结构化失败经验

### L3：长期记忆
- 位置：memory/agent/lessons/
- 状态：promoted
- 内容：验证过的失败教训
