# 钢铁意志·PI版 - 失败学习协议

## 更新时间
2026-06-02 19:31:29

## 这是什么
这是钢铁意志·PI版的失败学习协议，定义了失败经验如何转成结构化知识。

## 失败经验必须先转成 risk / anti-pattern / lesson / recommended_action
1. risk：风险描述
2. anti-pattern：反模式描述
3. lesson：教训总结
4. recommended_action：建议行动

## 为什么不能原样进长期层
1. 原样没有提炼，只是原始记录
2. 原样没有结构，不便于检索
3. 原样没有分析，不便于学习
4. 原样没有建议，不便于改进

## 为什么必须带 anchor_refs
1. 可追溯：可以追溯到原始失败场景
2. 可验证：可以验证失败的真实性
3. 可更新：可以在失败场景变化时同步更新
4. 可审计：可以审计失败的原因和影响

## 失败经验结构化格式
```markdown
# [失败标题]

## 元数据
- 锚点：[anchor_refs]
- 类型：失败经验
- 域：agent
- 状态：lesson
- 关键词：[关键词1, 难点词2]

## 风险 (risk)
[描述风险]

## 反模式 (anti-pattern)
[描述反模式]

## 教训 (lesson)
[描述教训]

## 建议行动 (recommended_action)
[描述建议行动]

## 来源
- 失败场景：[场景]
- 失败时间：[时间]
- 失败影响：[影响]
```

## 失败学习流程
```
失败发生
  ↓
记录原始失败
  ↓
结构化提炼
  ↓
添加元数据
  ↓
保留anchor_refs
  ↓
生成失败经验条目
  ↓
归档到lessons/
```
