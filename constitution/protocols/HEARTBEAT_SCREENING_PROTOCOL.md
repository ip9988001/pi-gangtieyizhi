# 钢铁意志·PI版 - Heartbeat筛选协议

## 更新时间
2026-06-02 19:21:35

## 这是什么
这是钢铁意志·PI版的Heartbeat筛选协议，定义了Heartbeat的定位和初筛规则。

## Heartbeat 的定位是日间整合器，不是深反思器
1. Heartbeat负责日间整合，不是夜间深反思
2. Heartbeat处理轻量级判断，不处理复杂分析
3. Heartbeat保持低噪音，不产生干扰
4. Heartbeat快速执行，不消耗过多资源

## 默认顺序是什么
1. 读取当日日志
2. 读取最近会话
3. 筛选值得保留的事实
4. 判断属于user还是agent
5. 生成候选条目
6. 更新候选状态

## Heartbeat 初筛时只做哪些轻量判断
1. 事实是否明确
2. 事实是否重要
3. 事实是否值得保留
4. 事实属于user还是agent

## 无变化时如何保持低噪音
1. 不生成空候选条目
2. 不更新无变化的状态
3. 不产生不必要的日志
4. 保持系统安静

## Heartbeat执行流程
```
Heartbeat触发
  ↓
读取当日日志
  ↓
读取最近会话
  ↓
筛选值得保留的事实
  ├─ 有 → 生成候选条目
  └─ 无 → 保持安静
  ↓
判断属于user还是agent
  ↓
更新候选状态
  ↓
结束
```
