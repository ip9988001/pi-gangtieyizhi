# 钢铁意志·PI版 - 多代理协作策略

## 更新时间
2026-06-02 19:55:32

## 这是什么
这是钢铁意志·PI版的多代理协作策略，定义了什么时候值得裂变。

## 什么时候值得裂变
1. 任务可以并行执行
2. 任务需要不同专业能力
3. 任务时间紧迫
4. 任务风险可控

## 主代理 / 子代理的职责边界
### 主代理职责
1. 任务分配
2. 结果聚合
3. 风险控制
4. 最终决策

### 子代理职责
1. 执行具体任务
2. 返回结果
3. 遵守mandate
4. 报告异常

## 协作流程
```
任务到达
  ↓
判断是否需要裂变
  ├─ 否 → 主代理执行
  └─ 是 → 裂变子代理
    ↓
  分配mandate
    ↓
  子代理执行
    ↓
  返回结果
    ↓
  主代理聚合
```
