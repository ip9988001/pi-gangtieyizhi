# 钢铁意志·PI版 - 宿主保护反应规则

## 更新时间
2026-06-02 19:59:18

## 这是什么
这是钢铁意志·PI版的宿主保护反应规则，定义了normal / guarded / hibernation的最低语义。

## normal 模式
- 条件：系统稳定
- 行为：执行所有任务
- 限制：无特殊限制

## guarded 模式
- 条件：系统不稳定
- 行为：只执行低风险任务
- 限制：禁止高风险任务

## hibernation 模式
- 条件：系统故障
- 行为：只执行恢复任务
- 限制：禁止所有非恢复任务

## 什么条件下拒绝继续裂变或高成本扩张
1. 资源不足
2. 风险过高
3. 时间不够
4. 用户拒绝

## 保护反应流程
```
系统状态变化
  ↓
判断是否需要反应
  ├─ 否 → 保持原状
  └─ 是 → 执行反应
    ↓
  切换保护模式
    ↓
  记录反应日志
```
