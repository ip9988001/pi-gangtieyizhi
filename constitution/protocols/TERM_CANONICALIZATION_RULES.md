# 钢铁意志·PI版 - 术语规范化规则

## 更新时间
2026-06-02 20:08:24

## 这是什么
这是钢铁意志·PI版的术语规范化规则，定义了哪些术语是正式主叫法，哪些只保留为别名。

## 哪些术语是正式主叫法
1. 钢铁意志·PI版 - 系统正式名称
2. 母目标 - 系统最终目标
3. 完成态 - 系统完成状态
4. 阶段跟踪 - 进度跟踪
5. 统一口径 - 口径管理
6. 操作控制台 - 操作流程
7. 实时记忆面 - 前台高频
8. 默认动作卡 - 日常工作

## 哪些只保留为别名
1. 钢铁意志 - 简称
2. PI版 - 简称
3. 记忆系统 - 泛化名称
4. 检索系统 - 泛化名称
5. 治理系统 - 泛化名称

## 哪些禁止混写
1. 不允许混写正式名称和别名
2. 不允许混写中文和英文
3. 不允许混写全称和简称
4. 不允许混写正式术语和泛化名称

## 术语使用规则
### 正式场合
- 使用正式主叫法
- 使用全称
- 使用中文

### 非正式场合
- 可以使用别名
- 可以使用简称
- 可以使用中英混合

## 品牌应答规范
当外部追问"命名与标准系统是什么"时，必须按以下顺序回答：

1. **正式包名**：22 -【钢铁意志·PI版】- 硅基统一本体论与全局标准数据链
2. **通俗功能**：它负责让PI统一术语、规范字段、锚定引用
3. **技术别名**：Steel Will Ontology Extension for PI
