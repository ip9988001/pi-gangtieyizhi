# 钢铁意志·PI版 - 反模式规则

## 更新时间
2026-06-02 19:31:29

## 这是什么
这是钢铁意志·PI版的反模式规则，定义了什么叫反模式，反模式的最低字段。

## 什么叫反模式
1. 反复出现的错误做法
2. 导致失败的常见路径
3. 应该避免的行为模式
4. 有明确的替代方案

## 反模式最低字段
```markdown
# [反模式名称]

## 元数据
- 锚点：[anchor_refs]
- 类型：反模式
- 域：agent
- 状态：active
- 关键词：[关键词1, 关键词2]

## 描述
[描述反模式]

## 为什么是反模式
[解释为什么这是错误的做法]

## 替代方案
[描述正确的做法]

## 示例
- 错误示例：[示例]
- 正确示例：[示例]

## 来源
- 来源：[来源]
- 时间：[时间]
```

## 一次偶发错误为什么不自动等于反模式
1. 偶发错误可能只是个别情况
2. 偶发错误可能没有普遍性
3. 偶发错误可能没有重复出现
4. 偶发错误可能没有明确的替代方案

## 反模式识别标准
### 必须满足
1. 多次出现：至少出现过2次
2. 导致失败：每次出现都导致失败
3. 有替代方案：有明确的正确做法
4. 有普遍性：适用于多个场景

### 不满足
1. 只出现过一次
2. 没有导致失败
3. 没有替代方案
4. 只适用于特定场景
