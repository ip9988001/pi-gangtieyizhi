# 钢铁意志·PI版 - 长期写回规则

## 更新时间
2026-06-02 19:24:27

## 这是什么
这是钢铁意志·PI版的长期写回规则，定义了长期层写入前必须遵守的规则。

## 长期层写入前必须"先读再写"
1. 读取目标文件（如果存在）
2. 比较内容差异
3. 判断是否需要更新
4. 执行写入操作
5. 记录写入日志

## 何时追加
1. 新增内容不与现有内容冲突
2. 新增内容是对现有内容的补充
3. 新增内容有明确的时间标记

## 何时更新
1. 现有内容需要修正
2. 现有内容需要补充
3. 现有内容需要更新

## 何时保留冲突
1. 内容存在矛盾
2. 无法判断哪个正确
3. 需要用户确认

## 长期写回流程
```
候选晋升
  ↓
读取目标文件
  ├─ 不存在 → ADD
  └─ 存在 → 比较内容
    ├─ 相同 → NOOP
    ├─ 不冲突 → UPDATE
    └─ 冲突 → CONFLICT
  ↓
执行写入
  ↓
记录日志
  ↓
更新导航
```
