# 钢铁意志·PI版 - INDEX导航协议

## 更新时间
2026-06-02 19:38:37

## 这是什么
这是钢铁意志·PI版的INDEX导航协议，定义了INDEX如何作为导航主入口。

## INDEX 是导航主入口，不是搜索工具附庸
1. INDEX是记忆系统的导航主入口
2. INDEX不是搜索工具的附庸
3. INDEX提供结构化的导航路径
4. INDEX提供关键信息的摘要

## INDEX 至少要指向当前高频目录、关键规则文件和关键运行面
### 高频目录
1. `memory/l1/` - L1原始碎片
2. `memory/candidates/` - L2候选筛选
3. `memory/agent/` - L3长期记忆
4. `memory/user/` - 用户记忆

### 关键规则文件
1. `START_HERE.md` - 单一入口
2. `STAGE_TRACKER.md` - 阶段跟踪
3. `UNIFIED_WORDING.md` - 统一口径
4. `OPERATIONS_CONSOLE.md` - 操作控制台

### 关键运行面
1. `NOW.md` - 当前状态
2. `HOT_MEMORY.md` - 热点记忆
3. `WARM_MEMORY.md` - 温点记忆

## 哪些内容应该只给路径和摘要，不前置全文
1. 大型文件
2. 详细规则
3. 历史记录
4. 备份文件

## INDEX格式
```markdown
# 钢铁意志·PI版 INDEX

## 高频目录
- [L1原始碎片](memory/l1/) - 原始事实记录
- [L2候选筛选](memory/candidates/) - 候选条目
- [L3长期记忆](memory/agent/) - 长期知识
- [用户记忆](memory/user/) - 用户相关

## 关键规则
- [单一入口](START_HERE.md) - 系统入口
- [阶段跟踪](STAGE_TRACKER.md) - 进度跟踪
- [统一口径](UNIFIED_WORDING.md) - 口径管理
- [操作控制台](OPERATIONS_CONSOLE.md) - 操作流程

## 关键运行面
- [当前状态](NOW.md) - 当前任务状态
- [热点记忆](HOT_MEMORY.md) - 高频访问
- [温点记忆](WARM_MEMORY.md) - 中频访问
```
