# 超短续接快照规则

## 定义

超短续接快照是一种极简的状态保存机制，用于在新窗口打开时快速恢复工作状态。

## 定位

- **不是**第二份NOW.md
- **不是**完整的工作日志
- **是**给新窗口秒恢复的极简快照

## 必要字段

### 1. current_goal (当前目标)
- **说明**: 当前正在处理的主要目标
- **示例**: "部署钢铁意志第二阶段"

### 2. current_stage (当前阶段)
- **说明**: 当前所处的工作阶段
- **示例**: "正在部署包23-幻觉剔除"

### 3. current_blocker (当前阻塞)
- **说明**: 当前遇到的主要阻塞或问题
- **示例**: "无"或"前置地基文件缺失"

### 4. next_action (下一步动作)
- **说明**: 下一步要执行的具体动作
- **示例**: "创建扩展文件"

### 5. must_read (必读文件)
- **说明**: 恢复工作前必须阅读的文件
- **示例**: "AGENTS.md, 包23部署文档"

## 可选字段

- `timestamp`: 快照创建时间
- `context`: 简短上下文说明
- `priority`: 优先级

## 快照规则

### 何时创建
1. **对话结束前**: 对话即将结束时创建
2. **重要节点**: 完成重要任务后创建
3. **阻塞时**: 遇到阻塞时创建

### 何时更新
1. **目标改变**: 当前目标改变时更新
2. **阶段推进**: 工作阶段推进时更新
3. **阻塞解决**: 阻塞解决时更新

### 何时删除
1. **任务完成**: 当前任务完全完成时
2. **目标失效**: 当前目标不再有效时

## 快照示例

```markdown
# 超短续接快照

## 元数据
```yaml
timestamp: "2026-06-03T10:30:00Z"
purpose: "新窗口秒恢复"
```

## 当前状态
- **当前目标**: 部署钢铁意志第二阶段
- **当前阶段**: 正在部署包23-幻觉剔除
- **当前阻塞**: 无
- **下一步动作**: 创建扩展文件
- **必读文件**: AGENTS.md, 包23部署文档
```

## 注意事项

1. **必须简短**: 不要写成长篇大论
2. **必须诚实**: 不要隐瞒阻塞或问题
3. **必须可续写**: 下一步动作要具体可执行
4. **不要膨胀**: 不要变成第二份NOW.md
