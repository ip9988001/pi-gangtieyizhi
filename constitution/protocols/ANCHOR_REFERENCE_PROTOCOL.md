# 钢铁意志·PI版 - 锚点引用协议

## 更新时间
2026-06-02 20:08:24

## 这是什么
这是钢铁意志·PI版的锚点引用协议，定义了anchor_refs什么时候必须出现。

## anchor_refs 什么时候必须出现
1. 长期知识记录时
2. 失败经验记录时
3. 决策记录时
4. 治理记录时

## 允许哪些锚点类型
1. 文件路径锚点
2. 时间戳锚点
3. 事件ID锚点
4. 人员锚点

## 无锚点时如何降级表述
1. 标记为"待确认"
2. 标记为"来源不明"
3. 标记为"需要验证"
4. 标记为"证据不足"

## 路径引用与证据引用的边界
### 路径引用
- 指向具体文件
- 指向具体目录
- 指向具体位置

### 证据引用
- 指向具体事实
- 指向具体数据
- 指向具体结果

## 锚点格式
```json
{
  "anchor_type": "file_path",
  "anchor_value": "~/.pi/agent/memory/goals/master-goal.md",
  "anchor_timestamp": "2026-06-02 20:08:24"
}
```
