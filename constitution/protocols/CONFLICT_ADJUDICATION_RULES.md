# 钢铁意志·PI版 - 冲突裁决规则

## 更新时间
2026-06-02 19:34:57

## 这是什么
这是钢铁意志·PI版的冲突裁决规则，定义了如何处理内容冲突。

## 冲突定义
当两个或多个内容对同一主题有不同描述时，就产生了冲突。

## 最低证据要求
1. 必须有明确的来源引用
2. 必须有时间标记
3. 必须有状态标记
4. 必须有冲突描述

## 必须保留的字段
1. 冲突ID
2. 冲突主题
3. 冲突内容
4. 冲突来源
5. 冲突时间
6. 冲突状态

## 什么时候挂起
1. 无法判断哪个正确
2. 需要用户确认
3. 需要进一步验证
4. 证据不足

## 什么时候能形成正式裁决
1. 证据充分
2. 来源可靠
3. 时间明确
4. 可以验证

## 为什么旧内容不能静默覆盖
1. 旧内容可能有历史价值
2. 旧内容可能有参考价值
3. 旧内容可能有追溯价值
4. 旧内容可能有审计价值

## 冲突裁决流程
```
冲突发生
  ↓
记录冲突
  ↓
收集证据
  ↓
判断是否可以裁决
  ├─ 是 → 执行裁决
  └─ 否 → 挂起等待
  ↓
更新状态
  ↓
记录裁决结果
```
