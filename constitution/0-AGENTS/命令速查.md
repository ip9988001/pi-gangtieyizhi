# 钢铁意志命令速查

> 当用户输入 `/` 开头的命令时，在此文件中查找对应命令并执行操作。

| 命令 | 功能 |
|------|------|
| `/steel-will-status` | 查看系统状态 |
| `/steel-will-entry` | 查看入口指引 |
| `/steel-will-stage` | 查看当前阶段 |
| `/steel-will-index` | 查看记忆索引 |
| `/recall-status` | 查看 recall_memory 状态 |
| `/workspace` | 查看当前工作区 |
| `/workspace-set <name>` | 切换工作区 |
| `/workspace-global` | 重置为全局工作区 |
| `/achievements` | 查看成就列表 |
| `/genre-status` | 查看体裁触发状态 |
| `/token-roi` | 查看 Token 节省回报 |
| `/promote` | 手动触发记忆晋升 L1→L2→L3→Wiki |
| `/promote-status` | 查看晋升管道状态 |
